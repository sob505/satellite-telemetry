IMPORTANT RULES:

- Each CSV file has a different schema.
- Do NOT combine rows from different files.
- Only use files that contain the required columns.
- Use pandas to read CSV files.
- Access columns by name (e.g., df["altitude_km"]).
- Do NOT use row indexing like row[0].
- All CSV files include headers.
